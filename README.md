# Concursos de datos e IA

Prepararse para los concursos de aprendizaje automático como los de Kaggle: leer la métrica, validar como el juez, cazar la fuga de datos, resolver cada familia de problemas (tabulares, series de tiempo, imágenes, texto, código con límites) y trabajar en equipo hasta la tabla privada.

**Ver en línea:** https://aaramirez.github.io/concursos-de-datos/

Este repositorio solo tiene el sitio generado. El curso está en preparación: la tabla de contenido ya está publicada para revisión.
